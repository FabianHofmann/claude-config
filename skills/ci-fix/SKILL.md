# CI Fix

Get the latest status from the CI build on Github related to the pull request (PR) associated with this branch. If you don't find a PR or all checks are passing, return and report your findings. Otherwise, identify the failing check(s) and fix them. Run the whole failing test suite locally to confirm the fix. Before committing and pushing your changes, let me approve them.
