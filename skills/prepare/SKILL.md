---
name: prepare
description: Write a concrete plan about a discussed or referenced implementation request.
---

Prepare a implementation plan about the discussed or following issue (to be figured out) and write it out in the `dev-scripts/<named-subfolder>/plan.md` or `dev/<named-subfolder>/plan.md` folder respective of which folder exists. If no `dev` or `dev-scripts` folder exist, create one and untrack it in gitignore.
